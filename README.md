Minecraft is a really cool game. And it's even more fun when you play with others. However, things can get confusing if tasks aren't properly coordinated amongst players. That's what inspired me to make this little project of mine. To keep it short, this is a CLI task management sytstem delevoped for Minecaft. It's meant to make administrative work in the game much easier. But above all, it's a project I'm using to hone my development skills as well as learn version control as this will be the first project I push to a GitHub repository.
